🏥 Smart Hospital Appointment System



A web-based hospital appointment management system developed using \*\*Java Servlets, JDBC, MySQL, HTML, and Apache Tomcat\*\*.



The application allows users to \*\*register patients, manage hospital appointments, and search patient/appointment records\*\* through a simple web interface. It demonstrates practical implementation of \*\*Java web development, servlet-based request handling, JDBC database connectivity, SQL operations, and MySQL integration\*\*.



\## 🛠️ Technologies Used



\- Java

\- Jakarta Servlets

\- JDBC

\- MySQL

\- HTML

\- Apache Tomcat

\- Eclipse IDE

\- Git \& GitHub



\## ✨ Key Features



\- Patient Registration

\- Appointment Management

\- Patient/Appointment Search

\- MySQL Database Integration

\- Servlet-based Request Processing

\- JDBC Connectivity
